# nest-metaapi

NestJS platform for MT5 Netting EA management and CopyFactory External Signals proof of concept.

- Source: custom MQL5 EAs on MT5 Netting accounts
- Followers: MT4 and MT5 Hedging demo accounts
- Development: Node.js 24, PostgreSQL 17, Redis, macOS, no Docker Compose
- Trading copying via CopyFactory external signals is **pending demo validation**.
- Standard CopyFactory Provider integration for MT5 Netting is excluded.

Do not commit credentials or enable live trading before validating the signal lifecycle.
